功能Features

歌词显示

  • 息屏(AOD) + 锁屏两个曲面独立开关与配置
  • 逐字卡拉 OK 高亮、整行扫光、辉光
  • 副行显示音标 / 翻译,可预览下一行,支持注音
  • 歌曲信息行:歌名 / 歌手 / 专辑自由拼装
  • 多种换行动画(含「跟随音源」)
  • 歌词时间偏移:±5 秒、50ms 一档

外观自由调

  • 字号 / 字重 / 字族,支持导入自定义字体
  • 主色 / 副色 / 信息色 / 卡片背景与透明度
  • 位置锚定、自定义纵向偏移、宽度占比
  • 横屏:随设备旋转、全屏化居中、安全边距
  • App 自身也定制:主题 / 背景图 / 悬浮底栏

息屏专属

  • 防烧屏:时钟图案移动与间隔可调
  • 实时跟随系统时钟 / 锚定两种模式
  • 亮度提升与自定义亮度
  • 渲染刷新率上限

歌词来源

  • Spicy EX(Spotify)
  • Lyricon / SuperLyric / LyricInfo
  • 插件系统:可扩展歌词处理链

工程化

  • 配置备份导出 / 导入(JSON)
  • 诊断日志、兼容性报告一键导出
  • 简体中文 / 繁体中文 / English

安装Install

  1. 准备一台 HyperOS 3 的小米 / 红米机型,并已解锁安装 LSPosed 框架。
  2. 从 GitHub Releases 下载最新 APK 并安装 (正式版日常使用;调试版仅用于反馈问题时提供日志)。
  3. 在 LSPosed 中启用模块,作用域勾选 系统界面(SystemUI) 与 息屏显示,按提示重启系统界面。
  4. 安装一个歌词源:手机里的 Spicy EX(Spotify)或 Lyricon / SuperLyric / LyricInfo 模块,App 内选择即可。
  5. 打开 HyperGlow CN+,先看「状态」页确认模块运行正常,再到「设置 → 外观」里调整样式。

详细排查(模块未生效 / 歌词不显示 / 不支持机型)见仓库 FAQ。
